# ScanDoc Offline

App de scanner de documentos HSE (PT, APR, Checklist, DDS, Outros) da equipe Cajuína.
Abre sem internet, guarda os documentos no celular e envia sozinho para o OneDrive quando o sinal volta.

Instalar: abra https://scan-cajuina.github.io/scandoc/ no celular e escolha "Adicionar à tela inicial" / "Instalar app".
